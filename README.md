# BLS Player

ブラウンノイズなどの背景音と、左右交互に鳴るタッピング音を再生するシンプルなブラウザ用プレーヤーです。再生時間や音量、タッピング音の周波数を設定できます。

## 起動方法

GitHub Pages で公開中のページは [https://tosh10.github.io/bls-player/](https://tosh10.github.io/bls-player/) です。ローカルで使う場合は、ビルドや依存パッケージのインストールは不要で、`index.html` をブラウザで開けます。音声を再生するには、ブラウザの自動再生制限により、画面上の「再生」ボタンを押す必要があります。

## 使い方

1. 背景音、タッピング音の周波数、各音量を設定します。
2. 必要に応じてタイマーを設定します。
3. 「再生」を押して開始し、もう一度押すと停止します。

## 音の設定

- **背景音:** ブラウンノイズ、ホワイトノイズ、テレビの砂嵐から選べます。再生中に変更すると、新しい背景音に切り替わります。
- **背景音の音量:** 0〜100%で調整できます。
- **タッピング音:** 左右のチャンネルで1秒ごとに交互に鳴る正弦波です。
- **周波数:** 40 Hz、174 Hz、432 Hz、528 Hzのプリセット、または1〜880 Hzの整数を指定できます。
- **タッピング音の音量:** 0〜100%で調整できます。

## タイマー

再生時間は1〜600分で設定できます。10分刻みの選択肢、または分数の直接入力が使えます。タイマーの時間が経過すると再生が停止します。「タイマーオフ」を押すと時間制限なしで再生できます。初期値は30分です。

## ファイル構成

- `index.html` — プレーヤー画面
- `index.css` — レイアウトとスタイル
- `index.js` — 再生、周波数、音量、タイマーの制御
- `resources/` — 背景音の音声ファイル

## 対応環境

Web Audio API とステレオパンに対応した最新のブラウザでご利用ください。音声が再生されない場合は、ブラウザの音量やサイトの音声設定を確認してください。
